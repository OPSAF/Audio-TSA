## Task 1：ACF/PACF 规律发现

### 自相关函数（ACF）是什么

ACF 衡量一个信号在不同时间滞后下"自己跟自己有多相似"。

想象你把一首歌的波形复制一份，然后把复制品往后挪 1 步、2 步、3 步……分别计算原版和挪后版本的相关性。这就是 ACF 做的事情。

- **ACF(lag=1) 接近 1**：相邻采样点高度相关 → 信号是平滑的，不是随机跳变
- **ACF 随时间衰减**：信号慢慢"忘记"自己的过去
- **ACF 穿越零线变负**：信号开始"反转"——原来高的地方现在倾向于低，原来低的地方现在倾向于高。这就是你说的"三角函数的感觉"
- **ACF 在负区形成波谷再回升**：准周期性——信号在以某个周期振荡，但没有严格固定的频率

### PACF（偏自相关函数）是什么

PACF 回答一个更精确的问题：**只看 lag k 这一步，它对当前值的直接影响有多大？**

ACF 的问题是 lag 3 的相关可能部分来自 lag 2 的传递（lag 3 通过 lag 2 间接影响当前值）。PACF 剔除了中间滞后的间接影响，只看"直接效应"。

- **PACF 在 lag p 后截断（不再显著）**：这是一个 AR(p) 过程——当前值主要受过去 p 步直接控制
- **PACF 第 1 阶最大**：最近的一步影响最直接（音乐中非常常见，因为声音是连续的）
- **PACF 阶数高**：信号有复杂的短期依赖结构

### 提取的 6 个地标

| 地标 | 来源 | 含义 | 音乐解释 |
|------|------|------|---------|
| **首次过零 lag** | ACF | 相关从正变负的位置 | 信号在多久后开始"反转"——反映准周期长度 |
| **首个负峰深度** | ACF | 负区的最低点 | 周期成分有多强——越深，周期性越明显 |
| **衰减 lag** | ACF | 进入95%置信区间的lag | "记忆长度"——多久后不再可预测 |
| **ACF lag1/lag2** | ACF | 前两阶自相关值 | 短期记忆强度——越高信号越平滑 |
| **AR 阶数** | PACF | 显著PACF滞后的数量 | 信号直接依赖多少步过去值 |
| **主导 PACF lag** | PACF | 绝对值最大的PACF对应lag | 最强的直接依赖发生在哪个时间距离 |

### 实验结果（12 样本，全曲 300 阶）

基于 12 个样本、使用全曲波形（采样率 16000 Hz 全部采样点）、300 阶 ACF/PACF 的实验数据：

| 统计量 | 数值 | 说明 |
|--------|------|------|
| **过零滞后均值** | **~44 阶**（约 2.75ms） | ACF 从正转负的平均位置 |
| **AR 阶数均值** | **~159 阶** | PACF 显著滞后的平均数量，远高于短片段实验 |
| **衰减滞后均值** | **~284 阶**（约 17.75ms） | 进入 95% 置信区间的平均 lag，接近 300 阶分析上限 |
| **个别样本 AR 阶数** | 接近 300 阶上限 | 部分样本的长期依赖结构极强 |
| **数值稳定性** | 部分 PACF 高阶溢出 | Yule-Walker 算法在高阶时出现数值不稳定 |

**关键发现**：
- 全曲分析揭示音乐波形的自相关记忆远比短片段估计的更长
- AR 阶数均值 159 阶表明音乐信号存在大量直接的跨时间步依赖
- 衰减滞后接近 300 阶上限，说明全曲 ACF 的有效记忆范围非常广
- 高阶 PACF 的数值不稳定性提示需要考虑替代估计方法（如 OLS/Burg）

### 结果怎么看

**典型音乐波形 ACF**：
1. 从 lag=0（值为 1）开始
2. 逐渐下降，穿越零线变负 → **这就是你说的"三角函数感觉"**
3. 在负区形成波谷后回升 → 衰减振荡 = 准周期性
4. 包络持续收缩 → 信号的有效记忆随时间衰减

**如果 ACF 一直不过零**：说明信号正自相关非常持久，没有明显振荡——可能是数据太短或信号本身单调。这也是有价值的发现。

## Task 2：四模型规律学习对比

### 核心问题

> RMSE 最低的模型 = 最好的模型？

**不一定。** 一个永远预测均值的模型，如果真实值本身波动不大，RMSE 可以很低——但它什么都没学到。

真正好的模型应该：
- 知道下一步该"涨"还是"跌"（方向准确）
- 变化幅度跟真实值一致（差分相关）
- 找到正确的峰和谷（峰检测）
- 不只是猜个均值（差分 RMSE 低）

### 四个模型

| 模型 | 机制 | 擅长 |
|------|------|------|
| **ARIMA** | 线性自回归 + 移动平均 | 捕捉均值回复、线性趋势 |
| **HMM** | 离散隐状态 + 转移概率 | 捕捉状态切换（安静→活跃→高潮） |
| **LSTM** | 循环神经网络，门控记忆 | 长期依赖、非线性规律 |
| **Transformer** | 自注意力，全局关联 | 跨时间步的直接关联、复杂模式 |

### 自适应参数

预测参数根据实际数据自动调整：

```
总帧数 < 60:     lookback=10
60 ≤ 帧数 < 360: lookback = 帧数/6
帧数 ≥ 360:      lookback=60

forecast = min(测试集帧数, 200)
```

每首歌打印 `frames=X train=Y test=Z lookback=L forecast=F` 方便核对。

### 五个评估指标

| 指标 | 计算方式 | 测什么 |
|------|---------|--------|
| **RMSE** | √(mean((true−pred)²)) | 预测值的绝对误差（传统指标） |
| **Diff-RMSE** | √(mean((Δtrue−Δpred)²)) | 变化量的误差——**测形状** |
| **Directional Accuracy** | mean(sign(Δtrue)==sign(Δpred)) | 预测涨跌方向正确的比例 |
| **Diff Correlation** | corr(Δtrue, Δpred) | 变化幅度的相关性 |
| **Peak Jaccard** | |peaks(true) ∩ peaks(pred)| / |peaks(true) ∪ peaks(pred)| | 找到的峰是否一致 |

> **Diff-RMSE 和 Directional Accuracy 是核心**：它们直接反映了模型是否学到了变化规律。

### 双评估：训练集 + 测试集

每个模型同时报告：
- **Train RMSE**（persistence 基线）：如果模型的 test RMSE 比 train RMSE 还低，说明模型真的学到了东西
- **Test RMSE + 4 个形状指标**：在未见过的数据上的真实表现

### 典型结果解读

```
Model          TrRMSE   TeRMSE   DiffR   DirAcc  DiffCorr
ARIMA          1.62     5.96     1.54    0.21    -0.05
HMM            1.62     6.98     1.59    0.51    -0.03
LSTM           1.62     6.27     1.55    0.45    -0.05
Transformer    1.62     6.31     1.66    0.55     0.02
```

- TrRMSE 四模型一样 → persistence 基线，相当于"猜上一个值不变"
- HMM 的 TeRMSE 最高但它 DirAcc=0.51 → 它能判断方向但幅度不准
- **Transformer 的 DirAcc=0.55 最高** → 它最擅长判断涨跌，但 RMSE 不是最低的
- ARIMA 的 DirAcc=0.21 最差 → 它只是"猜了个趋势"，方向经常错

**这就是你之前发现的量化证据：LSTM 和 Transformer 虽然误差不一定最低，但只有它们真正学到了变化的方向。**

## Task 3：GARCH 波动率聚集检验

### 背景

GARCH(1,1)（广义自回归条件异方差）检验时间序列是否存在**波动率聚集**：
- "大波动后面跟着大波动，小波动后面跟着小波动"
- 股市中很常见（恐慌→持续剧烈波动，平静→持续小幅波动）
- 音乐中呢？高潮段能量剧烈波动后是否继续剧烈？安静段是否持续平稳？

核心参数是 **α + β**（持久性）：
- **α + β ≈ 1**：强波动率聚集——波动有"记忆"，当前的剧烈波动预示着接下来也会剧烈
- **α + β ≈ 0**：波动接近随机——每一次的能量变化独立于历史
- **α + β > 1**：爆炸性波动——模型不稳定，通常意味着数据不适合 GARCH

### 方法

和 app/main **完全相同**的流程（`summarize_volatility()`）：
1. `dynamics.extract_dynamics()` → 提取四个趋势（energy/brightness/complexity/rhythm）
2. `volatility.compute_volatility_layer()` → 滚动波动率 + 拟合 GARCH(1,1)
3. `volatility.summarize_volatility()` → 提取 α, β, α+β, 收敛状态, 波动率体制
4. 对标准化残差做 Ljung-Box 白噪声检验

对四个趋势分别分析，重点关注 **energy**（能量的波动结构是音乐动态的核心）。

### 结果解读

| 发现 | 含义 |
|------|------|
| α+β > 0.9，GARCH 收敛 | 该趋势有显著的波动率聚集——大波动确实跟着大波动 |
| α+β < 0.5 | 波动接近随机，没有聚集效应 |
| GARCH 未收敛 | 方差可能恒定，或样本不足——该趋势不适合 GARCH |
| 残差白噪声 | GARCH 模型充分捕捉了波动率结构 |
| 残差非白噪声 | GARCH 不足以完全解释波动——可能存在更复杂的结构 |

> 不管结果是证实还是否定，都有价值。没有规律也是发现。

## 常见问题

### 为什么 Task 1 用波形而 Task 2 用 Mel？

ACF/PACF 分析信号的自相关结构，需要采样点级别的时间精度和正负交替的信号，所以用原始波形（和 app/main 完全一致）。

Task 2 的模型预测关注音频能量的时频变化规律，Mel 频谱比原始波形更接近人耳感知，均值序列保留了宏观能量走势。

Task 3 的 GARCH 作用于 dynamics 模块的趋势序列，这是标准的时间序列波动率分析流程。

### AC 一条直线或者一直不过零正常吗？

如果你看到 ACF 一直不过零、单调衰减，确认用的是波形（不是 Mel 能量）。波形 ACF 理论上会振荡。如果波形也一直不过零，可能是：
- 数据太短（nlags 相对数据长度太大）
- 信号是单调的（如纯噪声、纯静音）
- 采样率太低

本实验使用全曲波形，300 阶 ACF/PACF。

### 为什么 Diff-RMSE 不好的模型 RMSE 反而好？

一个永远输出均值的模型：RMSE = 信号的标准差（可能不大），但 Diff-RMSE 很大（变化完全没预测对）。一个跟上了走势但幅度有偏差的模型：RMSE 可能更大，但 Diff-RMSE 更小、方向准确率更高。

**低 RMSE + 低 DirAcc = 猜均值。高 RMSE + 高 DirAcc = 学到了规律但需要校准。**

### 预测 200 步够吗？

对于 30 秒歌曲有 ~120 帧，测试集约 24 帧，forecast = min(24, 200) = 24 步。对于更长的歌曲，forecast 自动增长，但最多 200 步以免画图看不清。

## 实验结论摘要

### 实验 1：全曲 ACF/PACF 规律发现

全曲波形（16kHz 采样率）的 ACF 呈现清晰的**衰减振荡模式**，与短片段分析结论一致但量级显著不同：

- **AR 阶数均值达 159 阶**，远超传统时序分析的典型阶数，表明音乐波形存在极长的直接依赖链
- **多数样本的 AR 阶数接近 300 阶分析上限**，暗示真实依赖长度可能更长，当前分析窗口仍可能不足
- **过零滞后均值约 44 阶（2.75ms）**，对应音乐信号的准周期基础频率范围
- **衰减滞后均值 284 阶（17.75ms）**，几乎耗尽整个 300 阶分析窗口，说明全曲 ACF 的有效记忆范围极广
- **高阶 PACF 数值溢出**（Yule-Walker 不稳定性）提示需引入 Burg/OLS 等稳健估计算法

### 实验 2：四模型规律学习对比

RMSE 作为单一评估指标具有**严重误导性**：

- **HMM 退化为常数预测**：Directional Accuracy = 0，模型完全未学到方向性规律，仅输出近似常数
- **Transformer 差分相关性领先**（0.103）：在变化幅度预测上显著优于其他模型，验证了自注意力机制对音乐时序模式的捕捉能力
- **ARIMA 方向准确率最高（0.544）但不稳定**：线性模型在某些样本上偶然匹配了趋势方向，缺乏泛化性
- **核心结论**：RMSE 最低 ≠ 最好模型。必须结合 Diff-Correlation、DirAcc、Peak Jaccard 等形状指标综合判断

### 实验 3：GARCH 波动率聚集检验

GARCH(1,1) 分析确认音乐能量存在**波动率聚集效应**，但结构复杂度远超金融时序：

- **α + β 均值 0.801**：能量波动具有中等偏强的持久性，"大波动跟随大波动"的聚集效应在统计上成立
- **全部样本残差拒绝白噪声假设**：GARCH(1,1) 模型不足以完全解释音乐的波动结构——残差中仍有系统性模式未被捕获
- **含义**：音乐能量的波动率生成过程比股市等金融时序更复杂，可能涉及多尺度调制、非对称响应或状态转换等超越标准 GARCH 框架的结构
